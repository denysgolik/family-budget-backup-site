Privacy Policy

Last updated: October 13, 2026

About the application

FamilyBudgetBackup is a personal utility used to create and store encrypted backups of a private family budget Telegram bot.

Google Drive access

The application uses Google Drive authorization to upload, retrieve, and manage encrypted backup files in the account authorized by the user.

Data storage and security

Backup files are encrypted locally using rclone crypt before being uploaded to Google Drive.

The application is not intended to share financial records with the public.

Data sharing

The application does not sell personal data or share backup contents with advertisers.

Data deletion

The user can delete stored backups from their Google Drive account and revoke access through Google Account security settings.

Contact

For questions about this application, contact the application developer using the contact email listed on the Google OAuth consent screen.
